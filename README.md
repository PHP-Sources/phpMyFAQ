# phpMyFAQ

<img src="https://github.com/PHP-Sources/.github/raw/main/logos/phpmyfaq.webp" width="48" height="48" alt="phpMyFAQ">

**phpMyFAQ 4.1.1** – Le système open source de FAQ (Foire Aux Questions) moderne, puissant et facile à utiliser.

### Points forts
- Gestion complète des questions/réponses avec catégories et tags
- Recherche full-text performante
- Support multi-langues
- Interface d’administration intuitive
- Système de commentaires et de votes
- SEO optimisé et compatible avec les moteurs de recherche
